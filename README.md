# Бункерні ваги PWA

## Основна логіка
- Точки тарування задають відповідність ваги напрузі.
- Межі повзунка незалежні від тарування, типово: -10.00...100.00 кг.
- Заповнення бункера розраховується від 0 кг до максимальної ваги тарування.
- Вага нижче 0 кг позначається як порожня тара та дає 0% заповнення.

## Локально
```bash
npm install
npm run dev
```

## GitHub Pages
Завантажте вміст папки у корінь репозиторію. В Settings > Pages виберіть Source: GitHub Actions. Push у main автоматично запустить публікацію.
