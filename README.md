# Калькулятор тензодатчика PWA

## Локальний запуск
```bash
npm install
npm run dev
```

## GitHub Pages
1. Створіть репозиторій та завантажте весь вміст архіву в корінь.
2. Гілка повинна називатися `main`.
3. Відкрийте **Settings → Pages → Build and deployment → Source** та оберіть **GitHub Actions**.
4. Після push workflow автоматично збере і опублікує застосунок.

`base: './'` дозволяє розміщувати проєкт у репозиторії з будь-якою назвою.

## PWA та офлайн
Після першого успішного відкриття опублікованої версії ресурси кешуються. Застосунок можна встановити через меню браузера або кнопку «Встановити», коли браузер її підтримує.
